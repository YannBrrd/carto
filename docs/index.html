Aperçu de l'application

Fonctionnalités

🗺️

Sélection polygonale

Dessinez des zones, ajustez les points par glisser-déposer, et arrondissez les angles avec la spline.

🎨

Thèmes personnalisables

Choisissez parmi les styles Maps, OpenStreetMap, ou créez votre propre palette de couleurs.

🖌️

Édition individuelle

Colorez des bâtiments, routes ou espaces naturels un par un. Sélection au clic ou par polygone.

📐

Export SVG haute qualité

Fichiers vectoriels avec calques Inkscape séparés : routes, bâtiments, eau, parcs...

🏷️

Noms de rues intelligents

Abréviations automatiques (Rue → r., Avenue → av.) et retour à la ligne si nécessaire.

🌍

Données OpenStreetMap

Accès à toutes les données OSM : routes, bâtiments, parcs, cours d'eau, POIs...

📴

Mode hors-ligne

Chargez des fichiers .osm locaux pour travailler sans connexion Internet. Idéal pour les zones sans réseau.

💻

Multiplateforme

Disponible sur Windows, macOS et Linux. Aucune installation requise (version portable).

Comment utiliser

1

Naviguez sur la carte

Utilisez la barre de recherche pour trouver une adresse, ou naviguez manuellement. Zoomez au niveau 15+ pour charger les données.

2

Dessinez votre zone

Cliquez sur "Nouvelle zone" puis cliquez sur la carte pour ajouter des points. Maintenez Ctrl pour déplacer la carte. Cliquez sur le point vert pour fermer. Ajustez les points par glisser-déposer, double-cliquez sur une ligne pour ajouter un point ou sur un point pour le supprimer.

3

Personnalisez le style

Choisissez un thème prédéfini ou modifiez les couleurs de chaque élément : routes, bâtiments, parcs, eau...

4

Exportez en SVG

Cliquez sur "Exporter SVG" pour générer un fichier vectoriel. Ouvrez-le dans Inkscape pour des modifications avancées.

Guide rapide

Tout ce qu'il faut savoir pour maîtriser Carto

⌨️ Raccourcis clavier

  • Ctrl + glisser — Déplacer la carte pendant le dessin
  • Molette — Zoomer / dézoomer
  • Clic sur point vert — Fermer le polygone
  • Glisser point bleu — Ajuster la forme après fermeture
  • Double-clic sur ligne — Ajouter un point sur le polygone
  • Double-clic sur point — Supprimer le point (min. 3 points)
  • Ctrl + clic — Sélectionner des points pour arrondir
Astuce : Double-cliquez sur une ligne pour ajouter un point, ou sur un point pour le supprimer. Sélectionnez des points consécutifs avec Ctrl+clic, puis "Arrondir" pour créer une courbe.

🎨 Thèmes et styles

  • Maps — Style clair et moderne
  • OpenStreetMap — Style classique OSM
  • Personnalisé — Créez votre propre palette
Astuce : Cliquez sur "Personnaliser" pour modifier individuellement les couleurs des routes, bâtiments, parcs et cours d'eau.

🖌️ Édition des couleurs

  • Mode Clic — Cliquez sur un élément pour le colorier
  • Mode Polygone — Dessinez une zone pour colorier plusieurs éléments
  • Catégories — Filtrez par bâtiments, routes, naturel ou cours d'eau
Astuce : En mode polygone, dessinez autour des éléments à modifier puis cliquez sur le point vert pour appliquer la couleur.

📐 Options d'export

  • Icônes POI — Affichez ou masquez les icônes de points d'intérêt (restaurants, écoles...)
  • Noms de rues — Cochez "Forcer tous les noms" pour afficher toutes les étiquettes
  • Voile extérieur — Ajoute un overlay gris hors de la zone sélectionnée
  • Couleur de bordure — Personnalisez la couleur du contour de la zone
Astuce : Le fichier SVG exporté contient des calques séparés (routes, bâtiments, eau...) pour faciliter l'édition dans Inkscape.

🔍 Navigation

  • Recherche — Tapez une adresse dans la barre de recherche
  • Zoom minimum — Niveau 15+ requis pour charger les données
  • Chargement — Attendez que les données soient chargées avant de dessiner
Astuce : Si les données ne se chargent pas, essayez de zoomer davantage ou d'attendre quelques secondes.

📴 Mode hors-ligne

  • Activation — Cochez "Mode hors-ligne" dans le panneau de gauche
  • Fichier .osm — Chargez un fichier exporté depuis openstreetmap.org
  • Labels — Les noms de rues et numéros sont affichés automatiquement
Astuce : Exportez une zone depuis openstreetmap.org/export pour obtenir un fichier .osm compatible.

💡 Bonnes pratiques

  • Petites zones — Préférez des zones réduites pour des exports plus rapides
  • Sauvegarde — Exportez régulièrement votre travail en SVG
  • Inkscape — Utilisez Inkscape pour les retouches finales
Astuce : Pour les grandes zones, divisez votre travail en plusieurs exports que vous assemblerez ensuite dans Inkscape.

Éditeur de Règles Avancé

Personnalisez le rendu cartographique avec des règles de style précises

⚙️ Présentation

  • Accès — Bouton "Éditeur de Règles Avancé" dans le panneau de gauche
  • Format — Compatible avec les fichiers .mrules de Maperitive
  • Préréglages — Maps et OpenStreetMap disponibles
Info : L'éditeur de règles permet un contrôle fin du rendu, au-delà des options de style simples.

📋 Onglets

  • Préréglages — Chargez un style prédéfini comme base
  • Features — Définitions des éléments cartographiques (routes, bâtiments...)
  • Règles — Propriétés de rendu pour chaque feature
  • Importer — Collez un fichier .mrules pour l'importer
Astuce : Exportez vos règles en .mrules pour les sauvegarder ou les partager.

🎨 Types de propriétés

  • Couleurs — line-color, fill-color, border-color, text-color
  • Dimensions — line-width, border-width, font-size
  • Opacités — fill-opacity, line-opacity (0 à 1)
  • Styles — line-style, border-style (solid, dash, none...)
Info : Les propriétés line-width et font-size peuvent être zoom-dépendantes.

🚫 Valeurs spéciales

  • none — Désactive le rendu (pas de ligne, pas de bordure)
  • Zoom-dépendant — Valeurs qui changent selon le niveau de zoom
  • Affichage — Les valeurs "none" apparaissent barrées dans l'éditeur
Exemple : line-style: none masque complètement le contour d'un élément.

🔧 Commandes de rendu

  • line — Dessine le contour (routes, chemins)
  • fill — Remplit la surface (bâtiments, parcs)
  • text — Affiche les labels et noms
  • icon / shape / shield — Symboles et icônes
Info : Cochez les commandes à activer pour chaque règle.

📁 Format .mrules

  • Compatibilité — Format inspiré de Maperitive
  • Structure — features: + rules: sections
  • Export — Bouton "Exporter .mrules" pour sauvegarder
Astuce : Éditez les fichiers .mrules dans un éditeur de texte pour des modifications avancées.
